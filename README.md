# SVD LGDS

An open-source React design system by **Studio Vitamin D**, built from Figma designs.

This repository will bring our Figma design system into code as reusable React components. The goal is to help designers and developers build consistent interfaces using shared design foundations, component variants, and interaction patterns.

## Project status

The project is in its initial setup stage. React components, tooling, and usage documentation will be added as development progresses. There is no installable component package yet.

## What we plan to build

- **Design foundations:** shared colors, typography, spacing, and other design tokens derived from Figma.
- **React components:** reusable UI components that reflect the designs, variants, and states defined in Figma.
- **Accessible interactions:** keyboard support, focus behavior, and appropriate semantics as part of component development.
- **Documentation and examples:** component APIs, usage guidance, and examples to help people adopt the system.

## From Figma to React

Figma will guide each component's visual design and behavior. Our intended workflow is to:

1. Review the component's design, variants, states, and responsive behavior in Figma.
2. Identify shared tokens and reusable patterns.
3. Implement the component in React with a clear, reusable API.
4. Check visual alignment, accessibility, and interaction behavior.
5. Document the component with practical examples.

Links to the Figma library will be added when available.

## Getting started

Clone the repository:

```bash
git clone https://github.com/StudiovitaminD/svd_lgds.git
cd svd_lgds
```

Installation, local development, and testing instructions will be added once the React tooling is configured.

## Contributing

Contributions are welcome, including component implementations, accessibility improvements, documentation, bug reports, and design feedback.

- Open an [issue](https://github.com/StudiovitaminD/svd_lgds/issues) to report a problem or discuss a proposed component.
- For larger changes, discuss the approach in an issue before starting implementation.
- Submit a pull request describing your changes and how you checked them. For UI changes, include screenshots and a relevant Figma reference when available.
